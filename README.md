# Task 03 – Interactive Visualization

## Project Title
HR Employee Attrition Analysis

## Objective
To create an interactive Tableau dashboard to analyze employee attrition and identify the major factors associated with employees leaving an organization.

## Tool Used
Tableau

## Dataset
HR Employee Attrition Dataset

## Dashboard Features
- Total Employees
- Employees Left
- Attrition Rate
- Average Monthly Income
- Attrition by Department
- Attrition by Age Group
- Attrition by Job Role
- Attrition by Job Satisfaction
- Attrition by Work-Life Balance
- Attrition by Overtime
- Attrition by Tenure

## Interactive Filters
- Region
- Age Group
- Department

## Key Question
Why are employees leaving?

## Key Insights
The dashboard helps analyze how overtime, job satisfaction, work-life balance, age, department, job role and tenure are associated with employee attrition.

## Output
The completed interactive Tableau dashboard is included in this repository.
